# Worldometers IVR API

מודול API קטן, יציב ו־Serverless שמביא בזמן אמת את הנתונים ש־[Worldometers](https://www.worldometers.info/iw/) מציג, ומחזיר אותם בפורמט נוח להקראה בשלוחת IVR של **ימות המשיח**.

בכל כניסה למודול מתבצעת **בקשה חדשה** לאתר המקור, כך שהמתקשר תמיד שומע את הנתונים העדכניים ביותר. אין מסד נתונים, אין Redis, אין אחסון קבוע, אין צורך ב־Token או במפתח API, ואין תלות בשירות חיצוני בתשלום.

## מה המודול עושה

- מוריד את דף הבית של Worldometers בעברית ומחלץ את **כל המונים** שהעמוד מציג (אוכלוסיית העולם, לידות, מקרי מוות, נתוני כלכלה, סביבה, בריאות ועוד) יחד עם התיאור בעברית של כל מונה.
- חושף שני נתיבי API:
  - `GET /api/worldometers` – מחזיר **JSON מסודר** עם כל הנתונים (לשילוב במערכות/עיבוד).
  - `GET /api/yemot` – מחזיר **טקסט בפורמט של ימות** שמוקרא ישירות למתקשר (תיאור בעברית + הקראת המספר).
- מטפל בשגיאות בצורה מסודרת: אתר לא זמין, שינוי במבנה האתר, נתון חסר, או timeout.

## מבנה הפרויקט

```
worldometers-ivr/
├── api/
│   ├── worldometers.js      # GET /api/worldometers  – מחזיר JSON
│   ├── yemot.js             # GET /api/yemot         – מחזיר טקסט לימות
│   └── _lib/
│       ├── worldometers.js  # הבאת הדף וחילוץ המונים (הליבה)
│       └── yemot.js         # בניית תגובת id_list_message לימות
├── scripts/
│   ├── test-parse.js        # בדיקת פרסור לא־מקוונת (fixture)
│   ├── test-local.js        # בדיקה מול האתר החי
│   └── fixture.html         # דוגמת HTML לבדיקות
├── vercel.json              # הגדרות פריסה (maxDuration)
├── package.json
└── README.md
```

> כל קובץ תחת `api/` שאינו בתיקיית `_lib` הופך אוטומטית ל־Serverless Function ב־Vercel. הקבצים ב־`_lib/` הם קוד משותף בלבד ואינם נחשפים כ־endpoint.

## התקנה מקומית

דרישה: **Node.js 18 ומעלה** (נעשה שימוש ב־`fetch` המובנה — אין תלויות חיצוניות כלל).

```bash
git clone <כתובת-הריפו>
cd worldometers-ivr

# בדיקת הפרסור (לא דורש אינטרנט)
npm run test:parse

# בדיקה מול האתר החי (דורש גישת רשת ל-worldometers.info)
npm run test:local
```

אין `npm install` הכרחי — אין תלויות ב־`dependencies`.

## פריסה ל־Vercel

1. התקינו את ה־CLI (פעם אחת): `npm i -g vercel`
2. מהתיקייה של הפרויקט הריצו:

   ```bash
   vercel          # פריסת תצוגה מקדימה
   vercel --prod   # פריסה לפרודקשן
   ```

   לחלופין: היכנסו ל־[vercel.com](https://vercel.com), לחצו **Add New → Project**, חברו את ה־repo מ־GitHub ולחצו **Deploy**. אין צורך להגדיר Environment Variables כלל.

3. בסיום תקבלו כתובת בסיס, לדוגמה:

   ```
   https://worldometers-ivr.vercel.app
   ```

## כתובות ה־API

לאחר הפריסה (החליפו `YOUR-APP` בשם הפרויקט שקיבלתם מ־Vercel):

| מטרה | Method | כתובת |
|---|---|---|
| JSON מלא | `GET` | `https://YOUR-APP.vercel.app/api/worldometers` |
| הקראה לימות | `GET` | `https://YOUR-APP.vercel.app/api/yemot` |

פרמטר אופציונלי ל־`/api/yemot`:

| פרמטר | ערך | הסבר |
|---|---|---|
| `limit` | מספר שלם חיובי | הקראת N המונים הראשונים בלבד (לקיצור השיחה). לדוגמה `?limit=5` |

## דוגמאות לבקשות ותשובות

### 1. `GET /api/worldometers`

בקשה:

```bash
curl https://YOUR-APP.vercel.app/api/worldometers
```

תשובה (מקוצר לדוגמה):

```json
{
  "ok": true,
  "source": "https://www.worldometers.info/iw/",
  "fetched_at": "2026-09-22T09:15:42.512Z",
  "count": 63,
  "counters": [
    {
      "id": "counter_1",
      "label": "אוכלוסיית העולם הנוכחית",
      "value": 8100000123,
      "value_text": "8,100,000,123"
    },
    {
      "id": "counter_2",
      "label": "לידות השנה",
      "value": 72000000,
      "value_text": "72,000,000"
    }
  ]
}
```

- `value` – המספר כערך מספרי (לעיבוד).
- `value_text` – אותו מספר מפורמט עם מפרידי אלפים (לתצוגה).
- `fetched_at` – זמן ההבאה בפועל (ISO‑8601, UTC).

### 2. `GET /api/yemot`

בקשה:

```bash
curl https://YOUR-APP.vercel.app/api/yemot
```

תשובה (טקסט רגיל, `text/plain; charset=utf-8`):

```
id_list_message=t-אוכלוסיית העולם הנוכחית.n-8100000123.t-לידות השנה.n-72000000&go_to_folder=hangup
```

פירוש: ימות תקריא את התיאור בעברית (`t-`), ואחריו את המספר כמספר מדובר (`n-`), עבור כל מונה, ואז תנתק (`go_to_folder=hangup`).

## הגדרת השלוחה בימות המשיח

יוצרים שלוחה מסוג **API** ומגדירים בקובץ `ext.ini` של השלוחה:

```ini
type=api
api_link=https://YOUR-APP.vercel.app/api/yemot
```

זהו. אין צורך בפרמטרים נוספים, בזיהוי משתמש, בהתחברות או במפתחות.

**איך זה עובד:** בכל כניסה לשלוחה ימות פונה ל־`api_link`. המודול מחזיר תגובת `id_list_message` (בפורמט המדויק של ימות), וימות מקריאה למתקשר את התיאור והמספר של כל מונה, ואז מנתקת.

### קיצור ההקראה (אופציונלי)

הקראת כל המונים עלולה להיות ארוכה. כדי להשמיע רק את המונים הראשונים:

```ini
type=api
api_link=https://YOUR-APP.vercel.app/api/yemot?limit=5
```

### חזרה לתפריט במקום ניתוק (אופציונלי)

ברירת המחדל מנתקת בסיום. אם תרצו שבסיום ההקראה המתקשר יחזור לשלוחה הראשית במקום שהשיחה תנותק, ערכו את `api/_lib/yemot.js` והחליפו את
`&go_to_folder=hangup` ב־`&go_to_folder=/` (מעבר לשלוחה הראשית) או ב־`&go_to_folder=/1` (מעבר לשלוחה מספר 1), ואז בצעו פריסה מחדש.

## פתרון תקלות נפוצות

| תסמין | סיבה אפשרית | פתרון |
|---|---|---|
| המתקשר שומע "האתר Worldometers לא הגיב בזמן" | האתר איטי / timeout (8 שניות) | תקלה זמנית — לרוב תיפתר בכניסה הבאה. אפשר להאריך את ה־timeout בקריאה ל־`getCounters({ timeoutMs })`. |
| המתקשר שומע "לא ניתן להתחבר לאתר Worldometers" | האתר לא זמין / חסימת רשת | בדקו זמינות של `https://www.worldometers.info/iw/` מהדפדפן. |
| המתקשר שומע "לא נמצאו נתונים... מבנה האתר השתנה" | Worldometers שינו את מבנה ה־HTML | עדכנו את הביטויים הרגולריים ב־`api/_lib/worldometers.js` (הפונקציה `parseCounters`). הרצת `npm run test:local` תראה מה מתקבל. |
| השלוחה לא מקריאה כלום | `api_link` שגוי או השלוחה אינה `type=api` | ודאו שהכתובת נכונה ומחזירה טקסט (בדקו ב־`curl`), וש־`type=api` מוגדר. |
| מספרים נקראים באנגלית | התשובה מתחילה באנגלית | המודול מחזיר תיאור בעברית תחילה (`t-`), כך שימות מקריאה בעברית. ודאו שלא שיניתם את סדר ההודעות. |
| השיחה ארוכה מדי | הרבה מונים | השתמשו ב־`?limit=N`. |

בדיקה מהירה שהכל תקין לאחר פריסה:

```bash
curl -i https://YOUR-APP.vercel.app/api/yemot
# מצופה: HTTP/200, Content-Type: text/plain, גוף שמתחיל ב- id_list_message=
```

## הערות ומגבלות

- **טריות הנתונים:** כל בקשה מביאה את הדף מחדש (`Cache-Control: no-store`). אין שמירת נתונים בין בקשות.
- **מקור הנתונים:** חלק מהמספרים ב־Worldometers מחושבים ב־JavaScript בצד הלקוח. המודול קורא את הערך שהעמוד מציג (טקסט המונה), ואם הוא ריק — את ערך הבסיס מתוך מאפיין ה־`rel` של המונה. כך מתקבלים הנתונים שהעמוד מציג בפועל, בלי צורך להריץ דפדפן מלא (מודול קטן ומהיר).
- **אחריות:** האתר שייך לצד שלישי; שינוי מבנה מצדם עלול לחייב עדכון קל של הפרסר (ראו טבלת התקלות).
- **קודי סטטוס:** `/api/worldometers` מחזיר קוד HTTP תואם לשגיאה (502/504/500). `/api/yemot` מחזיר תמיד `200` עם הודעת שגיאה קולית ברורה, כדי שהמתקשר ישמע הסבר במקום שקט.
