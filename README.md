# World Statistics IVR API

מודול API קטן, יציב ו־Serverless שמחזיר **סטטיסטיקה עולמית חיה** (בסגנון Worldometer) בפורמט נוח להקראה בשלוחת IVR של **ימות המשיח**.

## למה לא Worldometer ישירות?

בדקנו את אתר Worldometer בפועל: המספרים **אינם קיימים ב־HTML** של העמוד — הם נמשכים מוצפנים משירות חיצוני (`realtimestatistics.net`) ומחושבים אך ורק בדפדפן. לכן אי אפשר לשלוף אותם משרת בצורה אמינה, קטנה וחוקית.

במקום זאת המודול משתמש במקור **רשמי, פתוח ומדויק**: **World Bank Open Data API** (בנק העולמי) — ללא מפתח, ללא הרשמה, ללא מסד נתונים. ממנו מחושבים בזמן אמת אותם מונים מרכזיים ש־Worldometer מציג (אוכלוסייה, לידות, מקרי מוות, גידול), באותה שיטת חישוב (ערך שנתי רשמי + הקרנה לפי הזמן הנוכחי).

> **חשוב:** נתוני הבנק העולמי הם שנתיים (המדד האחרון זמין לשנה מסוימת). לכן כל נתון שמוקרא למתקשר מלווה במשפט **"מבוסס על נתוני שנת ____"**, כדי שיהיה ברור על איזו שנה מבוסס החישוב.

## מה המודול עושה

- בכל כניסה מבצע **בקשה טרייה** ל־World Bank API (אין שמירת נתונים מבקשה קודמת).
- מחשב מונים חיים לפי הזמן הנוכחי (UTC) והשיעורים הרשמיים.
- חושף שני נתיבים:
  - `GET /api/worldometers` — **JSON מסודר** עם כל הנתונים.
  - `GET /api/yemot` — **טקסט בפורמט ימות** שמוקרא ישירות למתקשר (תווית + מספר + שנת הבסיס).
- מטפל בשגיאות: מקור לא זמין, נתון חסר, או timeout.
- ללא Token, ללא מסד נתונים, ללא Redis, ללא אחסון קבוע, ללא שירות בתשלום.

## אילו נתונים מוחזרים

| מזהה | תווית (עברית) | חישוב | מבוסס על |
|---|---|---|---|
| `population_now` | אוכלוסיית העולם הנוכחית | אוכלוסייה רשמית מוקרנת לרגע הנוכחי לפי שיעור הגידול | נתוני אוכלוסייה (שנה אחרונה) |
| `births_today` | לידות היום | שיעור לידות × שניות מתחילת היום (UTC) | שיעור לידות גולמי |
| `births_this_year` | לידות השנה | שיעור לידות × שניות מתחילת השנה (UTC) | שיעור לידות גולמי |
| `deaths_today` | מקרי מוות היום | שיעור תמותה × שניות מתחילת היום | שיעור תמותה גולמי |
| `deaths_this_year` | מקרי מוות השנה | שיעור תמותה × שניות מתחילת השנה | שיעור תמותה גולמי |
| `growth_today` | גידול האוכלוסייה היום | לידות פחות מקרי מוות (היום) | שיעורי לידה/תמותה |
| `growth_this_year` | גידול האוכלוסייה השנה | לידות פחות מקרי מוות (השנה) | שיעורי לידה/תמותה |

המונים "היום"/"השנה" מתאפסים אוטומטית בחצות (UTC) ובראש השנה הלועזית, בדיוק כמו ב־Worldometer.

## מבנה הפרויקט

```
worldometers-ivr/
├── api/
│   ├── worldometers.js       # GET /api/worldometers  – מחזיר JSON
│   ├── yemot.js              # GET /api/yemot         – מחזיר טקסט לימות
│   └── _lib/
│       ├── worldstats.js     # הבאת נתוני World Bank + חישוב המונים (הליבה)
│       └── yemot.js          # בניית תגובת id_list_message לימות
├── scripts/
│   └── test.js               # בדיקת לוגיקה לא־מקוונת (mock ל-World Bank)
├── .github/workflows/
│   └── verify.yml            # בדיקה חיה מול World Bank (רץ ב-GitHub Actions)
├── vercel.json               # הגדרות פריסה (maxDuration)
├── package.json
└── README.md
```

> כל קובץ תחת `api/` שאינו בתיקיית `_lib` הופך אוטומטית ל־Serverless Function ב־Vercel. הקבצים ב־`_lib/` הם קוד משותף בלבד.

```bash
git clone <כתובת-הריפו>

```

## פריסה ל־Vercel

1. התקינו את ה־CLI (פעם אחת): `npm i -g vercel`
2. מהתיקייה של הפרויקט:

   ```bash
   vercel          # תצוגה מקדימה
   vercel --prod   # פרודקשן
   ```

   לחלופין: ב־[vercel.com](https://vercel.com) → **Add New → Project** → חברו את ה־repo מ־GitHub → **Deploy**. אין צורך ב־Environment Variables.

3. בסיום תקבלו כתובת בסיס, לדוגמה: `https://worldometers-ivr.vercel.app`

## כתובות ה־API

(החליפו `YOUR-APP` בשם הפרויקט מ־Vercel)

| מטרה | Method | כתובת |
|---|---|---|
| JSON מלא | `GET` | `https://YOUR-APP.vercel.app/api/worldometers` |
| הקראה לימות | `GET` | `https://YOUR-APP.vercel.app/api/yemot` |

פרמטר אופציונלי ל־`/api/yemot`:

| פרמטר | ערך | הסבר |
|---|---|---|
| `limit` | מספר שלם חיובי | הקראת N המונים הראשונים בלבד (לקיצור השיחה). לדוגמה `?limit=3` |

### 2. `GET /api/yemot`

```bash
curl https://YOUR-APP.vercel.app/api/yemot
```

תשובה (טקסט רגיל, `text/plain; charset=utf-8`):

```
id_list_message=t-אוכלוסיית העולם הנוכחית.n-8306311087.t-מבוסס על נתוני שנת 2025.t-לידות היום.n-185040.t-מבוסס על נתוני שנת 2024...&go_to_folder=hangup
```

פירוש: ימות מקריאה את התווית (`t-`), את המספר כמספר מדובר (`n-`), ואז את שנת הבסיס (`t-מבוסס על נתוני שנת ...`), לכל מונה, ולבסוף מנתקת (`go_to_folder=hangup`).

## הגדרת השלוחה בימות המשיח

יוצרים שלוחה מסוג **API** ומגדירים בקובץ `ext.ini` של השלוחה:

```ini
type=api
api_link=https://YOUR-APP.vercel.app/api/yemot
```

זהו. אין צורך בפרמטרים נוספים, בזיהוי משתמש, בהתחברות או במפתחות.

**איך זה עובד:** בכל כניסה לשלוחה ימות פונה ל־`api_link`. המודול מחזיר תגובת `id_list_message`, וימות מקריאה למתקשר את כל הנתונים (תווית, מספר, ושנת בסיס), ואז מנתקת.

### קיצור ההקראה (אופציונלי)

```ini
type=api
api_link=https://YOUR-APP.vercel.app/api/yemot?limit=3
```

### חזרה לתפריט במקום ניתוק (אופציונלי)

ברירת המחדל מנתקת בסיום. כדי לחזור לשלוחה הראשית במקום לנתק, ערכו את `api/_lib/yemot.js` והחליפו את `&go_to_folder=hangup` ב־`&go_to_folder=/` (שלוחה ראשית) או `&go_to_folder=/1` (שלוחה 1), ובצעו פריסה מחדש.

## פתרון תקלות נפוצות

| תסמין | סיבה אפשרית | פתרון |
|---|---|---|
| "מקור הנתונים לא הגיב בזמן" | World Bank איטי / timeout (8 שניות) | תקלה זמנית — תיפתר בכניסה הבאה. אפשר להאריך timeout בקריאה ל־`getWorldStats({ timeoutMs })`. |
| "לא ניתן להתחבר למקור הנתונים" | World Bank לא זמין / רשת | בדקו זמינות של `https://api.worldbank.org`. |
| "נתון חסר במקור עבור המדד ..." | הבנק העולמי שינה/הסיר מדד | עדכנו את מזהי המדדים ב־`api/_lib/worldstats.js` (אובייקט `INDICATORS`). |
| השלוחה לא מקריאה כלום | `api_link` שגוי או השלוחה אינה `type=api` | ודאו כתובת נכונה (בדקו ב־`curl`), ו־`type=api` מוגדר. |
| מספרים נקראים באנגלית | התשובה מתחילה באנגלית | המודול מחזיר תווית בעברית תחילה — ודאו שלא שיניתם את סדר ההודעות. |
| השיחה ארוכה מדי | הרבה מונים | השתמשו ב־`?limit=N`. |

בדיקה מהירה לאחר פריסה:

```bash
curl -i https://YOUR-APP.vercel.app/api/yemot
# מצופה: HTTP/200, Content-Type: text/plain, גוף שמתחיל ב- id_list_message=
```

## הערות ומגבלות

- **טריות:** כל בקשה מביאה מחדש את הנתונים מ־World Bank (`Cache-Control: no-store`).
- **דיוק:** הערכים החיים מוקרנים מנתונים שנתיים רשמיים (השנה מצוינת בכל נתון בשדה `as_of` ומוקראת למתקשר). לכן ייתכן פער קטן מול Worldometer, שמשתמש בהערכות עדכניות יותר. הסדר גודל והמגמה זהים.
- **תלויות:** אפס תלויות חיצוניות (Node 18+ עם `fetch` מובנה).
- **קודי סטטוס:** `/api/worldometers` מחזיר קוד HTTP תואם לשגיאה (502/504/500). `/api/yemot` מחזיר תמיד `200` עם הודעת שגיאה קולית ברורה, כדי שהמתקשר ישמע הסבר במקום שקט.
- **מקור:** [World Bank Open Data](https://data.worldbank.org) — נתונים פתוחים תחת רישיון CC BY 4.0.
